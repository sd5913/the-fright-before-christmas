# #11 排行榜示例版

日期：2026-11-10。任务分支：`TFBC-11-hiscore-table-with-placeholder-data`。

根据用户 2026-11-10 的新指示，排行榜改为独立页面 `/leaderboard/`，首页顶部的 High scores 链接跳转至该页。首页下方不再嵌入榜单。原 Issue #11 写的是游戏下方的表格，审核时需要同步本次确认的页面位置调整。

## 界面与数据

- 展示前 10 名、玩家名字、千分位格式的分数，按分数从高到低排列。
- 前三名采用独立领奖台：亚军左侧、冠军居中抬高、季军右侧，分别使用冰蓝、金色、粉色；冠军配备皇冠、聚光、光环与最大字号的分数。
- 修正首屏过高：桌面端（视口宽度至少 1000px）采用左侧领奖台、右侧第 4–10 名的布局，标题、人物与表格行高根据浏览器可用高度调整。使用正常文档流保留滚动，不通过隐藏溢出内容强行适配。
- Billy、Mandy、UFO 是示例领奖台的游戏主题装饰，不表示真实玩家头像或游戏中选择的角色。手机端同样保留三席领奖台，第 4–10 名在下方表格中展示。
- 标注 Sample scores，并说明成绩仅用于预览，游戏结果尚不写入当前榜单。
- 页面在 `src/pages/leaderboard.astro`；示例数据在 `src/data/demo-hiscores.ts`；展示组件在 `src/components/HiscoreTable.astro`，样式在 `src/styles/hiscores.css`。
- 数据通过组件的 entries 参数传入，本轮不调用 API、不模拟联网或保存成绩。后续 #13 可替换数据来源。
- 本轮没有修改 Unity、游戏导出文件或部署配置。

# #13 真实排行榜

日期：2026-11-11。分支：`TFBC-13-real-table-data`。

独立页面 `/leaderboard/` 已改为从 `https://metapool.cloud/tfbc-api/v1/scores?limit=10` 读取真实成绩。默认地址可直接使用，无需在 Railway 增加变量；需要切换环境时设置 `PUBLIC_API_BASE_URL` 并重新构建，参考根目录 `.env.example`。

## 已完成

- 删除产品代码中的演示成绩，首次打开页面和手动刷新时请求真实 API。
- 保留前三名领奖台和第 4–10 名表格。空位显示 Unclaimed 和破折号，不补假分数。
- 加载时禁用重复刷新；10 秒超时可重试。首次失败显示错误；刷新失败时保留上次成功的数据并明确提示，更新时间不变。
- 对完整响应校验后再更新页面，取消旧请求，避免迟到响应覆盖新结果。
- 玩家名字作为文本显示；支持 Unicode、负分及完整 32 位整数。长名字保留完整 title 与可访问名称。
- 保留键盘操作、减少动态效果和无 JavaScript 提示。宽屏继续使用左侧领奖台、右侧其余排名，避免首屏裁切。
- 首页本身不请求排行榜，也不提前请求 Unity 游戏资源；只在独立排行榜页面运行读榜脚本。

## 验证

- `npm.cmd run build` 和客户端 TypeScript 严格检查通过。
- `scripts/verify-leaderboard.cjs` 的 11 项浏览器检查通过：真实接口读取、加载、空榜、少量记录、刷新、失败恢复、保留旧数据、断网、错误响应、超时／迟到响应、文本安全及无 JavaScript 导航。
- 1920×980、1536×744、1366×640、1024×576 下，正常十条成绩在首屏可见；390px、320px 无横向溢出。
- 浏览器测试数据仅通过请求拦截提供，没有向正式 API 写入测试成绩。真实接口目前返回空榜，因此本地预览显示未认领席位。
- 截图和记录位于 `artifacts/leaderboard/`；文件名包含 fixture 的截图仅用于验证有成绩时的布局，不代表真实玩家数据。

复现浏览器检查需已有 Playwright 和 Chrome，设置 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 后执行 `node scripts/verify-leaderboard.cjs`。没有为产品新增浏览器或 UI 框架依赖。

## 边界

本任务仅修改前端页面、数据请求和样式；未修改后端服务、Unity 源码、游戏发布文件或云部署设置。代码推送到任务分支后，仍需按团队约定审核并合入部署分支，才会更新正式网站。游戏结束提交成绩由 #9 后续接入，不在本任务修改游戏。

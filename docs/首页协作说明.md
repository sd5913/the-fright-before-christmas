# 动态首页交付与协作说明

日期：2026-11-09。对应任务：#10（Logo）和 #14（Play Now）。

更新（2026-11-10）：按用户确认，将新生成的 Billy 六格动画（`billy-v7`）和原 Mandy 六格动画接入首页。人物资源位于 `public/assets/home/characters/`，来源和共同裁切范围见其中 `manifest.json`。Billy 六格以 1→2→3→4→5→6 正常顺序循环，每个源格播放一次；没有倒序、复制首帧或插帧。暂停时使用 `billy-poster-v7.webp`。Mandy 保持原版不变。

首页不再叠加原先的 CSS 人物呼吸缩放。人物 GIF 自身负责动作，容器继续使用轻微鼠标视差。由于 GIF 不能通过 CSS 暂停，进入游戏、页面隐藏、首页离开视口或减少动态效果时，脚本切换到同一动作的静态首帧；恢复首页后重新播放。动图加载失败也回退到首帧。

## 本次实现

- Astro 首页使用独立的卧室、Logo、Billy、Mandy、UFO 图层；星空、粒子、灯光和界面由网页渲染。
- 分层入场、人物轻微呼吸、UFO 漂浮、星空移动、灯串明暗、桌面鼠标视差及按钮光效。
- 当前人物的呼吸、点头和手部动作来自所选六帧 GIF，而非 CSS 对整张图片的缩放；不新增 Effects 开关。
- 按最新反馈移除 Effects 开关和 Play Now 下方的宣传文字。动效默认开启，不读取旧开关偏好；系统 `prefers-reduced-motion` 优先，触屏关闭鼠标视差。页面隐藏、首页离开视口或进入游戏后暂停首页动画。
- 点击前没有游戏 iframe，也没有 `/game/` 请求。点击后在原区域加载已有 `/game/index.html`，重复点击只生成一个实例。
- 入口请求失败或等待超过 30 秒提供重试；旧请求晚到不会覆盖新状态。返回首页会移除 iframe 并恢复按钮焦点。
- iframe 页面载入后展示 Unity 原有加载界面；网页不把 iframe 的 load 当作 Unity 已启动，不伪造游戏加载百分比。
- 保留原有项目、域名和部署方式。本次没有新增后端、排行榜、云服务或上线操作。

## Partner 文件边界

`Unity/` 和 `public/game/` 的文件完全未修改。人物、场景和原 Logo 仅作为新网页插画的参考；没有改模型、场景、C#、Unity Web 模板、构建文件或游戏控制逻辑。

网页不向 iframe 注入样式、不调用其内部对象，也不添加未经双方约定的游戏消息协议。游戏自身的布局、加载界面、错误显示和音频逻辑继续由原构建处理。首页自身没有音频。

## 以后需要协作的事项

这些事项不阻塞当前首页使用，也没有在本次替 partner 实现。

| 需求 | 首页目前行为 | 需要 partner 提供的配合 |
| --- | --- | --- |
| 精确显示“游戏已就绪” | 只确认入口 HTML 已载入；后续显示原游戏加载进度 | 从游戏／Web 模板提供稳定的就绪事件，并约定消息结构 |
| 捕获游戏内部加载失败 | 原 Unity 页面显示自身错误；首页只负责入口失败／超时重试 | 若需要首页统一报错，由游戏主动通知初始化失败，不能依赖 iframe load/error 判断所有资源状态 |
| 结算后自动刷新排行榜 | 本轮没有排行榜或结算监听 | #9 完成后，约定结算成功事件；#13 再接入刷新。postMessage 必须验证 origin、source 和结构 |
| 正式／测试 API 地址 | 首页未改变 Unity 配置 | #12 确定真实 URL 和协议后，由 partner 决定 Unity URL 的配置和构建方式；`public/game/` 不会自动读取 Astro `PUBLIC_*` |
| 手机游戏体验 | 网站入口适配触屏；提示游戏更适合鼠标键盘 | 触摸控制、WebGL 性能、游戏内部布局由游戏任务处理；本次未宣称游戏已适配手机 |
| 重新导出 Unity | iframe 路径保持 `/game/index.html` | 保持该入口及构建资源路径一致；首页无需覆盖或修改新导出文件 |

## 复现检查

Windows PowerShell 的执行策略可能阻止 `npm.ps1`，可以直接使用 `.cmd` 入口，无需改变系统策略：

```powershell
npm.cmd ci
npx.cmd astro dev --background
npx.cmd astro dev status
```

访问终端报告的 Local 地址，默认 `http://localhost:4321/`。服务管理：

```powershell
npx.cmd astro dev logs
npx.cmd astro dev stop
```

浏览器回归脚本为 `scripts/verify-home.cjs`。它需要独立可用的 Playwright 模块与 Chrome；不在产品包中新增浏览器运行依赖。如果环境中已安装 Playwright，可以直接运行：

```powershell
node scripts/verify-home.cjs
```

也可设置 `PLAYWRIGHT_MODULE` 为已有模块入口，`CHROME_PATH` 为浏览器可执行文件，`HOME_URL` 为测试地址；缺省使用 `playwright` 模块、已安装 Chrome channel 和 `http://localhost:4321`。脚本会重写 `artifacts/home/` 的回归截图及交互报告，真实 Unity 测试记录需要另行更新。

## 素材说明

生成工具：内置 imagegen。完整用途和提示摘要见 [ASSETS.md](../public/assets/home/ASSETS.md)。原五个静态 WebP 合计 459,378 bytes（约 449 KiB），当前网站使用其中的房间、Logo、UFO，并改用人物子目录的两张六帧 GIF 及首帧。人物来源、尺寸、时序与体积见 [manifest.json](../public/assets/home/characters/manifest.json)。没有字体 CDN、外部图片服务或额外 3D 引擎。

主提示方向：以现有游戏截图和已批准意向图为参考，分别生成无人物／无 UI 的卧室背景、保留原字形的透明 Logo、Billy 和 Mandy 透明全身插画、透明 UFO；保持粉白标题、紫色夜空和暖木质房间。人物和场景为 AI 辅助重绘的网页插画，不冒充游戏实时截图。
